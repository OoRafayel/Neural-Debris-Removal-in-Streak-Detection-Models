# Neural Debris Removal in Streak Detection Models

## Overview

This repository contains my solution for the Kaggle competition:
Neural Debris Removal in Streak Detection Models.

## Method

The method is based on:

- Activation analysis
- Poison channel pruning
- EWC regularization
- Feature suppression
- Backbone freezing
- Fine-tuning on unlearning set

## Environment

- Python 3.12
- PyTorch
- Detectron2
